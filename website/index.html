DISTRIBUTED. COORDINATED. RELIABLE.组件协作
Workite 分布式协作风筝 PD、Gateway、Broker、Worker 四个等规格组件节点共同构成风筝轮廓，中央是 Workite 品牌标识。PD 提供一致性协调，Gateway 统一接入，Broker 复制状态，Worker 并行执行业务。四类组件均可由多个实例组成，流光表达持续协作；具体通信关系见下方系统架构。

ACCESS

接入层，轻盈无状态。

Gateway 缓存拓扑，独立扩展。Client 与 Worker 都通过统一入口访问业务 API。

CONTROL

控制面，保持一致。

PD 用单一 Raft Group 复制元数据、注册租约和拓扑变更计划。

DATA

数据面，按分区协同。

每个分区独立复制与选主。Worker 向 PD 注册，通过 Gateway 激活与完成任务。

GO · 已连接 client，已部署 order 流程
// 用变量启动一个流程实例
response, err := client.
    NewCreateInstanceCommand().
    BPMNProcessID("order").
    Variables(map[string]any{"orderId": 42}).
    Send(context.Background())
if err != nil {
    log.Fatal(err)
}
log.Printf("instance %d",
    response.GetProcessInstanceKey())

片段来自 Go SDK。连接配置、资源部署和 Worker 示例见完整指南。

TERMINAL · demo 集群已配置并运行
cd clients/go
go build -o bin/wkctl ./cmd/wkctl
export WORKITE_CLUSTER_ID=demo

# 部署流程，创建实例
bin/wkctl deploy resource order.bpmn
bin/wkctl create instance order \
  --variables '{"orderId":42}'

# 为 payment 类型启动一个 Worker
bin/wkctl activate jobs payment --handler cat

准备 order.bpmn 文件。默认连接本地 Gateway :26500 与 PD :26501。
